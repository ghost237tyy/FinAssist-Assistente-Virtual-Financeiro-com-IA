# FinAssist — Assistente Virtual Financeiro com IA

## Sobre o projeto

O FinAssist é um assistente virtual voltado para educação financeira.

O projeto foi desenvolvido como parte da trilha Bradesco — Dados, Cibersegurança e GenAI da DIO.

## Objetivo

Criar uma experiência simples de atendimento financeiro utilizando conceitos de inteligência artificial, engenharia de prompt, base de conhecimento e Python.

## Funcionalidades

- Respostas sobre conceitos financeiros.
- Explicações sobre Pix.
- Explicações sobre cartão de crédito.
- Explicações sobre poupança.
- Explicações sobre juros.
- Orientações básicas de segurança financeira.
- Tratamento de perguntas fora da base de conhecimento.

## Tecnologias

- Python
- Inteligência Artificial Generativa
- Engenharia de Prompt
- Markdown
- GitHub

## Estrutura

- `documentacao.md` — documentação do agente.
- `base_conhecimento.md` — informações utilizadas pelo agente.
- `prompts.md` — prompts e exemplos de interação.
- `app.py` — aplicação funcional.

## Segurança

O projeto não solicita senhas, códigos de segurança, números completos de cartão ou outras informações sensíveis.

As informações possuem finalidade educacional e não constituem recomendação financeira personalizada.
